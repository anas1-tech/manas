# مانس كوفي: حاسبة التكاليف

موقع يحسب تكلفة كل كوب وربحه، مع منيو للزباين.

- **المواد**: تكتب سعر الكرتون وكم حبة فيه وحجم الحبة، والموقع يطلع سعر الحبة والجرام والمل.
- **المنتجات**: كم جرام أو مل من كل مادة في الكوب، مع شكل الكوب وهو يتعبى، والتكلفة والربح والسعر المقترح.
- **الخلطات (الدمج)**: مثل خلطة الكرك أو دلة القهوة. تحضّرها بكمية كبيرة وتصب منها في أكثر من منتج.
- **الضريبة**: إذا كنت مسجل أو مو مسجل، وإذا الأسعار شاملة أو لا.
- **Excel**: نموذج تعبيه وترفعه، وتقدر تصدّر بياناتك وتقرير التكاليف.
- **المنيو**: على الرابط `/menu`، يفتح بدون كلمة مرور، يتحدث كل دقيقة، وما يبين التكاليف.
- الحاسبة، ولوحة رئيسية، وسجل الأسعار، وتطبيق على الجوال (PWA)، ووضع ليلي، ونسخ احتياطي.

## التشغيل على جهازك

```bash
npm install
npm run dev
```

بدون إعدادات Supabase، الموقع يشتغل في **وضع تجريبي** والبيانات تنحفظ في المتصفح.

## الاستضافة: GitHub Pages

الموقع منشور على: **https://anas1-tech.github.io/mans-coffee-cost/**

- المنيو: https://anas1-tech.github.io/mans-coffee-cost/menu
- عشان تنشر أي تعديل: `npm run deploy`. هالأمر يشغّل الاختبارات ويبني الموقع ويرفعه على فرع `gh-pages`.

## قاعدة البيانات: Supabase (مرة وحدة)
1. ادخل https://supabase.com/dashboard وسوّ **New project**.
2. افتح **SQL Editor** والصق محتوى ملف `supabase/schema.sql` كامل، وبعدها **Run**.
3. افتح **Authentication ← Users ← Add user ← Create new user**، واكتب إيميلك وكلمة المرور، وفعّل **Auto Confirm User**.
4. افتح **Authentication ← Sign In / Providers** وطفّ **Allow new users to sign up** عشان ما أحد غيرك يسوي حساب.
5. افتح **Project Settings ← API** وانسخ **Project URL** و **Publishable key**، وحطهم في ملف `.env.production.local`:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_KEY=sb_publishable_xxxx
   ```
6. شغّل `npm run deploy`.

قبل ما تربط Supabase، الموقع يشتغل في **وضع تجريبي** والبيانات تنحفظ في المتصفح بس.

## تحديثات قاعدة البيانات
إذا كانت قاعدة البيانات قديمة، الموقع يطلع تنبيه فيه زر «انسخ الكود». الصق الكود في Supabase ← SQL Editor ← Run.
الملفات بالترتيب: `supabase/updates/002_units.sql` وبعده `supabase/updates/003_features.sql`. ما يضر لو شغّلتها أكثر من مرة.

## الموظفين
1. في Supabase افتح Authentication ← Add user، وسوّ للموظف إيميل مثل `ali@example.com`.
2. في الموقع افتح الإعدادات ← الموظفين، واكتب اسم المستخدم `ali` واختر صلاحيته (موظف أو مدير).
3. الموظف يدخل باسم المستخدم `ali`.
